## การเลือกภาพ

หัวข้อเกี่ยวกับความตาย จึงไม่มีภาพศพหรือภาพน่ากลัว ทั้งเรื่องใช้ภาพเปรียบเทียบแทน:

| ภาพ | ใช้แทน |
|---|---|
| ปลายนิ้วกระดาษ | เล็บ |
| คาง | ตอหนวด |
| โรงงานเซลล์ | ต้นกำเนิดเล็บที่ผลิตเซลล์ใหม่ |
| หัวใจกับเส้นคลื่นหัวใจ (ECG) | การหยุดทำงานของร่างกาย |
| องุ่นกลายเป็นลูกเกด | ผิวที่แห้งและหดตัว |
