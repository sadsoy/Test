# Storyboard — เราใช้สมองแค่ 10% จริงหรือ?

**แนวคิด:** ตัวเอกคือสมองกระดาษมีหน้าตา (brain buddy) ประกอบจากกลีบ 5 ชิ้นที่สว่างได้แยกกัน "แสงในกลีบ" จึงเป็นภาษาภาพหลักของทั้งเรื่อง: 10% สว่าง → ในหนังสว่าง 100% → ความจริงคือทุกกลีบผลัดกันสว่างตลอดวัน → ถ้าสว่างพร้อมกันหมดคืออาการชัก → วงออร์เคสตราที่ผลัดกันเล่น → วงแหวน 100% ที่กลีบยังผลัดกันสว่าง

**ความต่อเนื่อง:** กลีบทุกชิ้นเป็นรูปทรงตายตัว เปลี่ยนแค่สีและแสง
