# Assets — เหงื่อออกมากแปลว่าเผาผลาญไขมันมากจริงหรือ?

## ใช้ซ้ำจากโปรเจกต์

| ส่วน | ไฟล์ | ใช้ทำอะไรในคลิปนี้ |
|---|---|---|
| Engine | `src/core.js`, `src/timeline.js`, `render.mjs` | timeline, dissolve, paper grain, renderer แบบ 9:16 |
| Paper Cut kit | `src/shorts/paper.js` | ชั้นกระดาษ, เงา, เส้นใยกระดาษ, กล้อง parallax, แสงเรือง, ตัวอักษรกระดาษ |
| Props กลาง | `src/shorts/props.js` | ท้องฟ้า, ดวงอาทิตย์, เมฆ (ใช้เป็นไอน้ำและลมหายใจด้วย), ต้นไม้, เนินเขา |
| ตัวละคร | `src/shorts/sleepy/props.js` | ตัวละคร "อิ่ม" ตัวเดิม ใส่ชุดวิ่ง |
| ซับไตเติลไทย | `src/shorts/subs_th.js` | karaoke ทีละวลี และ `ph()` |
| Pipeline เสียง | `scripts/shorts_tts.py`, `shorts_voice.py`, `shorts_audio.mjs`, `shorts_transcribe.py` | `SHORT=sweat`: บท, ค่าตั้ง, ดนตรี และ SFX ของคลิปนี้ |

## ปรับระบบเดิมเท่าที่จำเป็น

| ไฟล์ | สิ่งที่ปรับ |
|---|---|
| `src/shorts/sleepy/props.js` | เพิ่มตัวเลือก `shirt` (สีเสื้อ) และ `band` (ผ้าคาดหัว) ให้ตัวละคร ค่าเริ่มต้นเหมือนเดิม |
| `src/shorts/paper.js` | แก้บั๊ก: ค่าโปร่งใสของชิ้นกระดาษ ข้อความ และเส้น (`o.alpha` และชั้นเส้นใยกระดาษ) เคยไปแทนที่การจางของกลุ่มที่มันอยู่ ตอนนี้คูณกันแทน ทำให้ชิ้นที่ควรจางหายตามกลุ่มไม่โผล่ขึ้นมา บั๊กนี้เจอตอนกล้องซูมเข้าหยดเหงื่อ ซึ่งภายในหยดโผล่ขึ้นมาบนหน้าตัวละคร |

## สร้างใหม่สำหรับคลิปนี้

| ไฟล์ | เนื้อหา |
|---|---|
| `shorts_sweat.html`, `src/shorts/sweat/config.js` | หน้าเรนเดอร์ 1080×1920 ที่ 30 fps |
| `src/shorts/sweat/props.js` | หยดเหงื่อ, เหงื่อกระเด็น, ชุดกันฝน, ตาชั่งดิจิทัล, หยดเหงื่อผ่าดูข้างใน (ชั้นน้ำและผลึกเกลือ), ก้อนไขมัน, โมเลกุล CO₂ และ H₂O, ลมหายใจ, เทอร์โมมิเตอร์, ขวดน้ำ, เปลวไฟ, ไอร้อน, ป้ายเตือน |
| `src/shorts/sweat/scenes.js` | 8 ช็อต ตั้งแต่ Hook ไปจนถึงปิด รวมทรานซิชันซูมดำดิ่งเข้าหยดเหงื่อ |
| `src/shorts/sweat/sound.mjs` | ดนตรี 104 BPM ใน G (สปอร์ต → โปร่ง → ค้างช่วงหักมุม → สดใส) และ SFX ประมาณ 70 จุดที่ผูกกับคำพูด |
| `src/shorts/sweat/narration.js`, `phrases.js` | เวลาของบรรทัดและวลี |
| `shorts/sweat/lines.json`, `take.json`, `voice.json`, `take1.wav` | บท, คำสั่ง TTS, ค่าการวางเสียง และเทคต้นฉบับ |
| `scripts/shorts_checkcuts.py` | เครื่องมือ QC ใหม่: เรียงทุกบรรทัดคั่นด้วยช่วงเงียบ แล้วถอดเสียงทีละช่วง ใช้แทนการถอดเสียงทีละไฟล์สั้นๆ ซึ่งไม่น่าเชื่อถือ |
