# Assets — ทำไมเราถึงรู้สึกง่วงหลังจากกินอาหาร?

## ใช้ซ้ำจากโปรเจกต์ (ไม่ได้แก้ไข)

| ส่วน | ไฟล์ | ใช้ทำอะไรในคลิปนี้ |
|---|---|---|
| Engine | `src/core.js`, `src/timeline.js`, `render.mjs` | timeline, dissolve, paper grain, renderer และขนาดภาพ 9:16 ที่เพิ่มไว้ตอนทำคลิปพลังงานสะอาด |
| Paper Cut kit | `src/shorts/paper.js` | ชั้นกระดาษ, เงา, เส้นใยกระดาษ, กล้อง parallax, แสงเรือง, ตัวอักษรกระดาษ |
| Props กลาง | `src/shorts/props.js` | ท้องฟ้า, เมฆ, ดวงอาทิตย์, ต้นไม้, เนินเขา, ก้อนแร่ (ใช้เป็นไก่ทอดในจานใหญ่) |
| ซับไตเติลไทย | `src/shorts/subs_th.js` | karaoke ทีละวลี และฟังก์ชัน `ph()` ให้ภาพเข้าจังหวะคำ |
| Pipeline เสียง | `scripts/shorts_tts.py`, `shorts_voice.py`, `shorts_audio.mjs`, `shorts_transcribe.py` | TTS, การตัดและวางบรรยาย, เครื่องมือสังเคราะห์ดนตรีและ SFX, การมิกซ์, การถอดเสียงเพื่อตรวจ |

## ปรับระบบเดิมเท่าที่จำเป็น

| ไฟล์ | สิ่งที่ปรับ |
|---|---|
| `scripts/shorts_voice.py` | เพิ่ม `SHORT=<slug>` ให้อ่านบทและค่าตั้งของคลิปนั้น (`shorts/<slug>/lines.json`, `voice.json`) แล้วเขียนผลลงโฟลเดอร์ของคลิปนั้น |
| `scripts/shorts_audio.mjs` | เพิ่ม `SHORT=<slug>` ให้ใช้ช่วงเพลง คอร์ด และ SFX จาก `src/shorts/<slug>/sound.mjs` |
| `src/shorts/subs_th.js` | ถ้าวลีเดียวยาวเกินบรรทัด จะย่อขนาดตัวอักษรของบรรทัดนั้นแทนการล้นออกนอกจอ |

ทั้งสามจุดไม่เปลี่ยนผลของคลิปพลังงานสะอาด: เมื่อไม่ตั้ง `SHORT` เสียงมิกซ์ที่สร้างใหม่ตรงกับไฟล์เดิมทุกไบต์ และในคลิปนั้นไม่มีวลีไหนยาวเกินบรรทัด

## สร้างใหม่สำหรับคลิปนี้

| ไฟล์ | เนื้อหา |
|---|---|
| `shorts_sleepy.html`, `src/shorts/sleepy/config.js` | หน้าเรนเดอร์ 1080×1920 ที่ 30 fps |
| `src/shorts/sleepy/props.js` | ตัวละคร "อิ่ม" (หัว, ผม, ตาที่มีเปลือกตาเลื่อนปิด, แก้ม, ปากยิ้มหรือหาว, พุงป่องได้, แขนยกได้, ขาเดินได้), ตัว Z ลอย, จานข้าวแกงไข่ดาวที่ค่อยๆ หมด, จานใหญ่, จานสมดุล, สมอง, กระเพาะ, ลำไส้ขด, ก้อนน้ำตาล, เซลล์ออเร็กซินแบบโคมกระดาษ, หน้าปัดวัดความง่วง, นาฬิกา |
| `src/shorts/sleepy/scenes.js` | 8 ช็อต (Hook, ความเชื่อ → ความจริง, พักและย่อย, ออเร็กซิน, ขนาดมื้อ, จุดหักมุม + กราฟ, วิธีแก้, ปิด) |
| `src/shorts/sleepy/sound.mjs` | ดนตรี 96 BPM ใน F (เพลย์ฟูล → ลอย → ค้างช่วงหักมุม → อบอุ่น) และ SFX ประมาณ 60 จุดที่ผูกกับคำพูด |
| `src/shorts/sleepy/narration.js`, `phrases.js` | เวลาของแต่ละบรรทัดและแต่ละวลี |
| `shorts/sleepy/lines.json`, `take.json`, `voice.json`, `take1.wav` | บท, คำสั่ง TTS, ค่าการวางเสียง และเทคบรรยายต้นฉบับ (เก็บไว้ใน repo เพราะ `out/` ไม่ได้ commit) |
| `scripts/shorts_checklines.sh` | ถอดเสียงทีละบรรทัดเพื่อจับจุดตัดที่ตัดกลางคำ |
