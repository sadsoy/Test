# Storyboard — ถ้าโลกเปลี่ยนไปใช้พลังงานสะอาดทั้งหมด?

**Logline:** โลกที่ "ถอดปลั๊ก" ฟอสซิลจะเป็นอย่างไร? คลิปพาไปจากโลกสีควันในวันนี้ สู่แดด ลม แบตเตอรี่ และ Smart Grid
แล้วหักมุมว่าไฟฟ้าเป็นแค่ 1 ใน 5 ของพลังงานที่ใช้ อุตสาหกรรมหนักยังเปลี่ยนยาก และพลังงานสะอาดก็ต้องใช้แร่
จากนั้นจึงปิดด้วยภาพอนาคตที่ต้องสร้างขึ้นจริง และคำถามว่า "เราจะไปถึงเร็วแค่ไหน?"

**สไตล์:** Paper Cut เป็นชั้นกระดาษตัด มีเงานุ่มที่เข้มขึ้นตามความสูงของแต่ละชั้น มีเส้นใยกระดาษในทุกชิ้น
และใช้ paper grain กับ vignette ของ engine เดิม (`core.js`) ปิดทับทั้งเฟรม กล้องเป็น parallax 4–5 ชั้น ขยับแบบ dolly, crane และ push-in

**สีตามเรื่อง:**

| โลก | โทนสี |
|---|---|
| ฟอสซิล | น้ำตาลควัน เทา สนิม แสงไฟจากปล่องเผาสีส้ม |
| สะอาด (กลางวัน) | มิ้นต์ ฟ้า เขียวเนิน ขาวกังหัน |
| กลางคืน / Smart Grid | น้ำเงินกรมท่า มีพลังงานเรืองสีเหลืองและเขียวมิ้นต์ |
| หักมุม | กระดาษครีมด้าน ไฟฟ้าเป็นสีเหลือง |
| ปิดเรื่อง | ฟ้าใส แล้วจบที่อวกาศ |

**ลำดับเหตุผลของภาพ:** ปลั๊กฟอสซิลถูกตัด → โลกสีควัน → แดดขึ้น แผงโซลาร์กางออก → กลางคืน ลมหยุด แบตเตอรี่จ่ายไฟให้เมือง →
Smart Grid เชื่อมทุกจุด → แต่ไฟฟ้าเป็นแค่ 1 ใน 5 → อุตสาหกรรมหนักยังมีควัน → แร่จากเหมืองต้องมาก่อน →
อากาศใสขึ้น (สถานการณ์สมมติ) → โลกทั้งใบต่อสายถึงกัน → คำถามปลายเปิด
